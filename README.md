# Portfolio Web — Salma Sajid

Bienvenue sur mon portfolio ! Ce site présente mon parcours, mes expériences, mes projets et mes compétences en génie logiciel. Je l'ai conçu comme un espace personnel et professionnel, avec une attention particulière portée à l'ergonomie, à l'accessibilité et à l'expérience utilisateur.

## Technologies utilisées

- **HTML & CSS** — Structure du site, mise en page responsive et thèmes visuels.
- **JavaScript** — Animations, interactions, navigation et gestion des langues.
- **Git & GitHub** — Gestion des versions et publication du projet.

## Fonctionnalités

- **Trois langues :** français, anglais et arabe, avec une mise en page adaptée à la lecture de droite à gauche (RTL).
- **Affichage personnalisable :** modes clair et sombre, ainsi qu'une palette de couleurs adaptée.
- **Navigation responsive :** interface adaptée aux ordinateurs, tablettes et téléphones.
- **Contenu interactif :** expériences détaillées, carrousel de projets et animations au défilement.

## Structure du projet

```text
portfolio/
├── index.html                  # Page principale du site
├── css/                        # Styles, thèmes, animations et responsive
│   ├── base.css
│   ├── themes.css
│   ├── responsive.css
│   └── arabic-rtl.css
├── javascript/                 # Interactions et comportements du site
│   ├── language.js             # Traductions FR / EN / AR
│   ├── theme.js                # Thèmes et couleurs adaptées
│   ├── navbar.js               # Navigation et menu mobile
│   └── home-designs.js         # Carrousel des projets
├── images/                     # Photos, illustrations et logos
├── documents/                  # CV téléchargeable
└── README.md                   # Présentation du projet
```

*L'arborescence présente les principaux fichiers ; les dossiers CSS et JavaScript en contiennent d'autres.*

## Accès au site

Le portfolio est un site statique : aucune installation ni compilation n'est nécessaire.

Pour le consulter en local, ouvre le dossier du projet dans **Visual Studio Code**, puis lance `index.html` avec l'extension **Live Server**.

**Site en ligne :** [Accéder à mon portfolio](https://sjsalma.github.io/portfolio/)

**Code source :** [GitHub — SjSalma/portfolio](https://github.com/SjSalma/portfolio)

## Mise à jour du contenu

Les textes et les sections se trouvent dans `index.html`. Les traductions sont regroupées dans `javascript/language.js` ; toute nouvelle formulation doit être adaptée aux trois langues. Les styles sont organisés dans `css/`, notamment pour les thèmes, le responsive et l'affichage en arabe.

Avant publication, vérifier que les liens, les images et le téléchargement du CV fonctionnent dans les trois langues, sur ordinateur comme sur mobile.
